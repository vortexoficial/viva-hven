# Assets - Viva Haven

## Imagem do Morador

Para substituir o placeholder da seção "App do Morador":

1. Criar/obter uma imagem PNG de uma pessoa (morador) sem fundo (transparente)
2. Dimensões recomendadas: 280-400px de largura, proporção vertical
3. A pessoa deve estar de corpo inteiro ou da cintura para cima
4. Renomear o arquivo para `morador.png`
5. Colocar na pasta `assets/`
6. Atualizar o HTML em `index.html` linha ~479:
   - Mudar de: `assets/morador-placeholder.svg`
   - Para: `assets/morador.png`

### Dicas para a imagem:
- Use PNG com fundo transparente
- A pessoa deve parecer estar "olhando pela janela" do card
- Evite imagens muito grandes (max 500KB)
- Considere usar ferramentas como remove.bg para remover o fundo
